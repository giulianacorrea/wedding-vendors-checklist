# 💍 Checklist do Sim
 
Aplicação web para organizar os preparativos de um casamento: cadastre tarefas, acompanhe o que já foi feito e consulte um cronograma com sugestões para cada etapa até o grande dia.
 
**[Acessar o site](https://giulianacorrea.github.io/wedding-vendors-checklist/)**
 
## Funcionalidades
 
- Cadastrar, concluir e excluir tarefas
- Desfazer a última tarefa cadastrada
- Registrar valor, fornecedor e observações de cada tarefa
- Informar a data do casamento e gerar um cronograma automático de preparativos
- Salvar tudo no navegador com `localStorage`
- Layout responsivo e recursos de acessibilidade
## Tecnologias
 
HTML5, CSS3 e JavaScript puro (sem frameworks).
 
> Os dados ficam salvos apenas no navegador usado, sem sincronizar entre dispositivos.
